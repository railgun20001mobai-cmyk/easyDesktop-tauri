# easyDesktop-tauri

一个 Windows 桌面整理工具：把桌面图标收进一块贴边面板，桌面本身保持干净。鼠标移到屏幕角落（或按自定义全局热键）就唤出面板，打开文件、进入目录、分类筛选、应用组、新建与重命名都在这一处完成。

本仓库是 [vicent-yx/easyDesktop](https://github.com/vicent-yx/easyDesktop)（pywebview + Python 版）的重写版：功能与交互对齐上游，后端改用 Rust + Tauri v2，安装后不再需要 Python 环境。上游基线为 `2.9.0`（commit `5108267`），本项目独立编号，自 `1.0.0` 起。

![license](https://img.shields.io/badge/license-GPL--3.0-green) ![platform](https://img.shields.io/badge/platform-Windows-blue) ![framework](https://img.shields.io/badge/Tauri-v2-orange)

## 快速开始

1. 到 [Releases](https://github.com/railgun20001mobai-cmyk/easyDesktop-tauri/releases) 下载 `easyDesktop-tauri_1.0.0_x64-setup.exe` 安装（约 9.4 MB）
2. 启动后面板默认停在屏幕角落，鼠标移到左下角即可唤出，移开后自动收起
3. 想彻底腾出桌面：在桌面右键 → 查看 → 取消勾选"显示桌面图标"，之后所有桌面文件都通过面板访问
4. 程序常驻托盘，点托盘图标或齿轮可进入设置；卸载用安装目录里的 `uninstall.exe`

需要 WebView2 Runtime（Windows 11 自带，Windows 10 可在安装设置中勾选自动下载，或另行安装 Evergreen Runtime）。

## 界面与用法

### 唤出与收起

- 角落热区唤出，或自定义全局热键唤出（组合键可在设置里改）
- 面板可停靠位置、收起方式（离开面板即收 / 失焦即收）、热区大小都可配置
- 全屏程序前台时不会误弹、不会抢焦点；支持多显示器与副屏
- 系统托盘常驻，支持开机自启（可选以较高优先级启动）

### 浏览与打开

- 面板展示当前目录内容，默认为桌面；单击图标进入子目录，面包屑与返回按钮可逐级回退
- 右键菜单：打开、在资源管理器中显示、复制、粘贴、重命名、删除、新建文件 / 文件夹 / 应用组、自定义图标
- 新建支持 docx / xlsx / pptx / txt 与文件夹；粘贴支持从资源管理器复制来的内容
- 顶部搜索框过滤当前目录，支持拼音全拼与首字母
- 图片文件预生成缩略图并缓存，滚动时不再等待解码

### 分类

分类是这块面板里最常用的一块：把当前目录（默认就是桌面）里的文件按"待办""素材""常用软件"这类主题归成一个集合，需要时一键唤出。文件仍留在原目录，分类只负责把它们聚到一起。

- 面板左侧是一列分类：固定的「全部」在最上方，往下是自建分类。点一个就把当前视图过滤成该分类的成员，再点「全部」恢复
- 切换分类是一段"手机桌面翻页"动效：旧内容朝你翻的方向退场、新内容从另一侧进场，方向跟着分类栏的位置走
- **滚轮切分类**：指针停在分类栏上滚滚轮——栏内还能往这个方向滚时先滚列表，滚到尽头再继续滚就切到上一个 / 下一个分类，选中的分类按钮会自动滚进可视区。分类攒得多时，不必在竖排按钮上瞄准点击，连着滚就能翻过去
- 栏底的「+ 新建分类」：在弹出的选择框里勾文件、起名字，一次建好
- 右键任意分类：改名或调整成员，改名后仍留在栏里原来的位置
- 分类顺序可以直接拖拽调整（「全部」固定首位），常用的拉到最上面
- 图标上的分类角标可点：在当前分类里点一下就把这个文件移出 / 移入该分类，边浏览边整理
- 分类与应用组、拖拽排序、视图切换互不干扰，过滤状态下照样能多选与拖动重排

### 应用组

- 一个组图标对应一个程序集合：拖文件到组图标上即加入，进入组视图后拖出即移出
- 组视图里可调整成员顺序、单独打开某个成员；右键组图标可重命名或删除该组
- 组图标与普通图标一样参与拖拽重排、搜索与多选

### 多选与拖拽排序

- `Ctrl` + 点击逐个多选，`Shift` + 拖动框选一片，`Esc` 取消选择
- 拖动图标时原位被其他图标填满，不留下空位；只有一个跟手的虚槽，其余图标实时让位
- 落点按图标的左半边 / 右半边判定（整行视图按上半 / 下半），判定带迟滞，指针在中线来回蹭也不会反复换位
- 拖起预览：3 个以内叠真实图标，超过 3 个叠前三个并显示数量角标
- 拖拽过程中可用**滚轮**翻页，长列表不必松手重来
- 框选与拖拽都可以翻页：指针贴到可视区边缘时列表自动滚动
- 网格视图与整行列表视图共用同一套重排逻辑与动效
- 排序结果按目录持久化，重启后保持

### 视图与外观

- 网格视图 / 整行列表视图切换，带进出动效；切换按钮的图标提示"点下去会切到哪一面"
- 深色 / 浅色 / 自定义主题，配色可改
- 毛玻璃强度、背景图、界面缩放均可调

## 本改版相对原版的改进

### 技术栈

|  | 原版 | 本改版 |
| --- | --- | --- |
| 后端 | Python + pywebview | Rust + Tauri v2 |
| 渲染 | pywebview 封装的系统 WebView | WebView2 |
| 第三方库 | Pillow、keyboard、pynput、icoextract、darkdetect 等 | 编译期并入二进制，运行时不再依赖 |
| 运行环境 | 需随包带上 Python 解释器与上述库 | 单个 exe，安装包约 9.4 MB |
| 后端代码量 | 十余个 Python 模块，约 7000 行 | 7 个 Rust 模块，约 3900 行 |

前端仍是原生 HTML + CSS + JS，未引入框架与打包器；资源在打包时内嵌进可执行文件。

### 布局

原版用 `.box1` / `.box2` 两层 90° 旋转把竖排"凑"成横排，再靠负 `marginTop` 做几何补偿把内容拉回顶部，改尺寸或加缩放就容易错位。本改版去掉这两层变换与补偿，改为标准的两列 flex 布局：左侧固定宽度分类竖栏 + 右侧文件区，栏底放「+ 新建分类」。同时把滚动收拢到文件区内部——header 固定、卡片高度按面板剩余空间固定，滚轮滚的是图标而不是整页。

### 动效

原版的动效只有零散的 `transition`，没有统一的时间与缓动约定。本改版按 Material Design 3 的节奏建立了一组 CSS 变量形式的 motion token（进场减速、退场加速、非对称时长），面板进出、视图切换、分类翻页、图标重排与悬停反馈全部走同一套 token，目前引用点约一百处：

- 面板滑入用减速曲线、滑出用加速曲线，时长与 Rust 侧的动画帧控对齐
- 分类切换做成"手机桌面翻页"：旧内容朝翻页方向退场（110ms）、新内容从另一侧进场（190ms），只动 `transform` 与 `opacity`，不复制 DOM、不触发重排
- 图标重排用 FLIP：先记录旧位置，重排后反向位移再补间到新位置，因此"让位"是连续的而不是瞬间跳格
- 悬停、选中、按钮反馈等微交互统一走 quick 时长与强调型缓动
- 长列表只对本次视口内的图标做补间：一百多项的整行视图重排，单帧补间的图标数从"全部"降到视口内的约 8 个

### 交互

原版的批量操作只有单击打开和一套原生拖拽排序，多选、框选、滚轮相关的能力都是本改版新增的：

- `Ctrl` 点击多选、`Shift` 拖动框选（自绘橡皮筋，贴边自动翻页）
- 手机桌面式重排：抓起时原位被填满，全程只有一个跟手虚槽，其余图标实时让位
- 落点判定覆盖图标左右两半（整行视图为上下两半），并加 0.15 的迟滞带，指针在中线来回蹭不会反复换位
- 拖拽中的滚轮翻页：原生 HTML5 拖拽期间浏览器会屏蔽 `wheel`，因此整套拖拽换成指针事件自绘，这是换掉它的主因
- 分类栏滚轮切换分类，配合翻页动效，分类多时连续滚就能翻完
- 整行列表视图与网格视图共用同一套多选、框选与重排逻辑

### 稳定性

- 修复快速连点视图切换按钮导致面板整片空白：切换被打断时残留的退场状态没有被清掉
- 修复切换分类时先闪一帧"全部"：分类成员改为本地缓存，过滤在渲染前同步生效
- 视图切换按钮的图标状态改为从实际 DOM 推导，不再与显示状态脱节
- 前台是全屏应用时改用温和的抢焦点方式（不注入 Alt、不附加线程输入队列），避免面板与全屏游戏互相抢焦点导致反复弹出收起
- 整页滚动收拢到文件区内部，贴边收起的热区判定与副屏坐标换算统一到 Rust 侧，多显示器下行为一致

## 技术实现

JS 侧通过 `pywebview_shim.js` 兼容层把调用转发到 Rust 的单一入口 `pywebview_call`，由它按方法名分发到约 43 个后端方法，因此前后端的行为可以与上游 Python 版逐条对照。窗口权限只声明 `core:default`（见 `capabilities/default.json`），不注册额外插件权限、不加载远程内容；由于桌面文件可能位于任意磁盘位置，本地资源协议（`asset:protocol`）的路径范围放得较宽。

```
.
├── src/
│   ├── main.rs        窗口、角落唤出与自动收起、热键、托盘、面板动画
│   ├── api.rs         pywebview_call 分发：文件操作、配置、分类、应用组
│   ├── files.rs       目录扫描、排序持久化、新建 / 重命名 / 删除
│   ├── icons.rs       系统图标提取与缓存、自定义图标
│   ├── preview.rs     图片缩略图
│   ├── config.rs      config.json / user_class.json / user_groups.json 读写
│   └── win32.rs       Win32 互操作：前台窗口、全屏检测、圆角、光标、尺寸
├── frontend/
│   ├── easyFileDesk.html       面板骨架与内联样式
│   ├── pywebview_shim.js       调用桥适配层
│   ├── resources/ed.js         前端主逻辑：渲染、拖拽、框选、分类、应用组、主题
│   ├── resources/file_icos/    文件类型图标
│   ├── theme/frame.css         布局与动效
│   └── theme/theme.css         配色变量
├── capabilities/default.json   Tauri 权限声明
├── icons/                      应用图标
└── Cargo.toml / build.rs / tauri.conf.json
```

## 构建

环境：Windows 10 / 11、Rust stable、Node.js LTS。

```bash
# 开发调试（前端改动热重载）
npx @tauri-apps/cli@2 dev

# 编译 release
cargo build --release

# 生成 NSIS 安装包，产物在 target/release/bundle/nsis/
npx @tauri-apps/cli@2 build --bundles nsis
```

前端资源在构建时内嵌进可执行文件，只改 `frontend/` 下的文件同样需要重新构建才生效。

## 数据与备份

用户数据全部保存在安装目录，卸载程序不会静默删除，迁移新机时整体拷走即可：

| 文件 / 目录 | 内容 |
| --- | --- |
| `config.json` | 全部设置：触发方式、热键、面板尺寸与位置、视图、主题、缩放、各目录的图标顺序 |
| `user_class.json` | 分类定义与成员 |
| `user_groups.json` | 应用组 |
| `desktopICO/` | 提取出的图标缓存，可安全删除（会自动重建） |
| `background/` | 自定义背景图 |
| `ed_calls.log` | 运行日志，用于排查问题 |

## 常见问题

**鼠标移到角落没反应**
检查设置里的触发方式与停靠位置是否被改动；确认托盘里程序在运行；若开了全局热键，可直接用热键唤出。

**面板挡住全屏游戏 / 游戏里唤不出**
设置里可切换为"仅失焦收起"，并调整收起判定；全屏程序前台时面板不会主动抢焦点。

**没有毛玻璃效果**
毛玻璃依赖系统 DWM 的透明效果，系统"性能选项"里关闭透明或远程桌面环境下会被禁用。

**改了文件名，图标没变**
图标有缓存，删除安装目录下的 `desktopICO/` 后重启程序即可重新提取。

**滚分类栏时翻不动分类**
栏内还有内容没滚到头时滚轮优先给列表滚动，滚到底（或顶）之后继续滚才会切分类。

**卸载后想彻底重来**
删除安装目录下剩余的 `config.json`、`user_class.json`、`user_groups.json` 与缓存目录即可。
